## Why

变更哨兵与可拖动人偶目前各自占据右下角，信息入口重复且容易互相遮挡。将哨兵能力融入人偶，可让人偶成为明确、低干扰的运维状态入口。

## What Changes

- 以可拖动人偶作为变更哨兵的唯一入口，移除独立的右下角哨兵触发器。
- 人偶保留原有 Agent 情绪，并叠加事件流连接状态、风险色光环与未读数量角标。
- 点击人偶时在其上方展开并复用现有变更事件面板；拖动只移动人偶位置，不触发面板。
- 新事件到达时在人偶上方短暂显示一条摘要，避免常驻大卡片。

## Capabilities

### New Capabilities

- `pet-sentinel`: 通过人偶感知、打开和处理变更哨兵事件。

### Modified Capabilities

- 无。

## Impact

- 前端：`FloatingCompanion`、`ChangeEventSentinel` 与主布局中的浮层组合。
- 交互：变更事件仍使用既有 SSE、已读和清空能力；不新增后端 API 或持久化。
